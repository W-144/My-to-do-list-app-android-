# 🗓️ Smart To-Do & Glance Widget

An elegant, time-aware Android productivity dashboard built entirely with Kotlin and modern Android architecture. This app doesn't just list your tasks; it brings them to your home screen with a beautiful, mathematically spaced two-column grid widget designed for maximum information density.

✨ Core Features

🏠 Premium Home Screen Widget: A highly optimized Jetpack Glance widget featuring a glassmorphism design and responsive two-column layout.

⏳ Dynamic Countdowns: The app safely calculates and visually displays the exact days remaining until your task deadlines (e.g., "3 days left", "Overdue").

🎨 Material 3 Dynamic Theming: The UI beautifully adapts to your system wallpaper and color palette dynamically.

⚡ Zero Bloat: Pure native performance with no background battery drain.

🛠️ Tech Stack & Architecture

Language: 100% Kotlin

UI Toolkit: Jetpack Compose & Compose Glance

Architecture: MVVM (Model-View-ViewModel)

Local Storage: Room Database

Concurrency: Kotlin Coroutines & Flow

🚀 Getting Started

For Users (Install the App)

Want to just use the app?
Head over to the Releases tab and download the latest app-release.apk to install it directly on your Android device.

For Developers (Build from Source)

Clone this repository:

```Bash
git clone https://github.com/W-144/My-to-do-list-app-android-.git
```
Open the project in Android Studio (or VS Code with Kotlin extensions).

Let Gradle sync the dependencies.

Build and run the app module on your emulator or physical device.
